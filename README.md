# Avalanche victim detection dashboard

Interactive dashboard of two test flights of a drone carrying a software-defined radio, searching for a radio beacon (avalanche-victim detection capstone project).

- **Overview:** all flights, flight videos with live graphs that follow the video, signal-strength and likelihood charts, a satellite map, and photos from the test day.
- **Flight 005 tab:** the full analysis for that flight.

Open the live page at the GitHub Pages link in the repository's About box. The page loads its charts and map tiles from public CDNs, so it needs an internet connection.
